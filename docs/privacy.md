# プライバシーポリシー / Privacy Policy

## 日本語

卓鯖ビルダー（以下「本アプリ」）のプライバシーポリシーです。

- 本アプリは個人情報を収集・送信しません。開発者のサーバーは存在しません。
- 通信先は Discord API（discord.com）と、アップデート確認のための GitHub（github.com / api.github.com）のみです。Microsoft Store 版はアップデート確認を行いません。
- Bot トークン・サーバーID・プリセット・アップロード画像はユーザーのPC内にのみ保存されます。Windows 配布版ではトークンは OS の暗号化機能で暗号化されます。
- アナリティクス・広告・クラッシュレポートの送信はありません。
- お問い合わせ先: GitHub Issues https://github.com/reverinudog/takusaba-builder/issues

最終更新日: 2026-09-17

---

## English

This is the privacy policy for TakusabaBuilder ("the app").

- The app does not collect or transmit any personal information. There is no developer-operated server.
- Network communication is limited to the Discord API (discord.com) and, for update checks, GitHub (github.com / api.github.com). The Microsoft Store build performs no update checks.
- The bot token, server ID, presets, and uploaded images are stored only on the user's PC. In the Windows distribution build, the token is encrypted using the operating system's encryption feature.
- No analytics, advertising, or crash-report transmission.
- Contact: GitHub Issues https://github.com/reverinudog/takusaba-builder/issues

Last updated: 2026-09-17
