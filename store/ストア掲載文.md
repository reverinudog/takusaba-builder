## 短い説明（200字以内）

TRPGの卓ごとに手作業で作っていたDiscordチャンネル一式を、保存したプリセットからまとめて作成・片付けできるGM向けデスクトップツールです。

## 説明（全文）

TRPGのセッションを開くたびに、Discordで「概要」「日程調整」「雑談」「キャラシ提出」といったチャンネルを手作業で作る手間に悩んで作りました。
よく使うチャンネル構成を「プリセット」として保存しておくことで、卓を立てるときに必要なチャンネルを一括で作成し、セッションが終わったらカテゴリごとまとめて削除できるデスクトップアプリです。

■ できること
・プリセットの作成と保存
卓で毎回使うチャンネル構成（テキスト／ボイス／GM用秘匿チャンネル）や、最初に自動投稿する案内文・画像をプリセットとして保存できます。

・卓チャンネルの作成
プリセット・卓名・参加者を選ぶだけで、参加者だけに見えるカテゴリとチャンネル一式が作られ、案内文も自動で投稿されます。

・終了した卓の片付け
役目を終えた卓は、カテゴリごと中のチャンネルもまとめて削除できます。手動で1つずつチャンネルを消していく手間がかかりません。

■ こんな方におすすめです
・定期的に卓を立てていて、チャンネルの手動作成を手間に感じているGM
・卓ごとに、参加者だけが見えるチャンネル一式をまとめて用意したい方
・終了したセッションのチャンネルがサーバーに溜まっていて整理したい方

■ 初期設定について
アプリの動作にはDiscordの「Bot」を1つ作成する必要がありますが、アプリ内のセットアップ画面でBotの作成から接続確認まで順番に案内します（所要時間は5分ほどです）。プログラミングなどの専門知識は必要ありません。

■ 動作環境
・Windows 10 / 11（64bit、Arm版も対応）
・Discord サーバーの管理者権限（ご自身で作ったサーバーであれば問題ありません）
・インターネット接続

■ ご利用にあたっての注意点
・本アプリはDiscord以外とは通信しません。設定内容や保存したプリセットがお使いのPC外へ送信されることはありません。
・Discord側の仕様変更などにより、将来的に動作しなくなる可能性があります。最新版はGitHub（https://github.com/reverinudog/takusaba-builder/releases）にて無料で公開・更新しています。

## 審査員向けメモ（Notes for certification）

This app automates creation and cleanup of Discord channel categories for tabletop RPG sessions. It requires a Discord bot token provided by the user — there is no built-in account.

To review the app end-to-end:
1. Open the Discord Developer Portal (https://discord.com/developers/applications) and create a New Application.
2. In the application's "Bot" section, click "Reset Token" to obtain a bot token. Enable the "Server Members Intent" toggle under Privileged Gateway Intents.
3. Invite the bot to a test Discord server with Administrator permission using the OAuth2 URL Generator (scope: bot).
4. Launch the app; the in-app setup wizard walks through the same steps (language selection → paste token → select server → automatic permission checks).
5. After setup, presets can be created and a test category can be created/deleted from the "卓を立てる" (Run) screen.

The app communicates only with the Discord API. No data is sent to any other server.
